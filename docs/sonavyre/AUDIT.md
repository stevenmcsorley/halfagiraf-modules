## Programs and provenance

The supplied standard bank contains eight assembled FV-1 algorithms and 24 explicit bypass slots. The eight actual effects are Room Reverb, Plate Reverb, Stereo Delay, Ping-Pong Delay, Chorus, Flanger, Tremolo and Pitch Shift. They retain slots 0–7. The supplied advanced bank contains 200 program binaries with names and parameter labels; they occupy full-edition slots 8–207. An additional 38 binaries from the supplied offline editor catalogue occupy slots 208–245. The complete catalogue has 238 unique binaries; the full module exposes 246 slots including the original eight effects.

Inclusion of the program binaries and metadata is explicitly authorized by the owner. Public download availability is not the basis for inclusion. The editor's firmware image/container is excluded. The original assembly generator and separate SpinASM files are absent from the supplied tree; this is a provenance inventory note, not a demonstrated build failure or release prohibition.

`OriginalBank.hpp` and `CompleteBank.hpp` retain the original program words and control metadata with neutral source identifiers/comments. `CatalogueExtras.hpp` is reproduced and checked by `tools/gen_sonavyre_catalogue.py`. `FreeBank.hpp` and `StudioBank.hpp` are generated by `tools/gen_sonavyre_editions.py`; their 12/64 selected programs are compared byte-for-byte against the supplied banks. The baseline revision and SHA-256 hashes for regression inputs are in `REFERENCE-SOURCES.json`. No claim is made that rebranding created these original DSP programs.

## Architecture and functionality

- Shared `engine/Engine.hpp` adapts the existing advanced host: original gain/mix, stereo/CV routing, clock interpolation, three internal LFOs and ten patch preset slots.
- `core/FV1.hpp` preserves the original VM processing implementation.
- `engine/Composition.hpp` adds two preallocated FV-1 stages for PRO, serial/parallel routing, per-stage controls and global mix/bypass. Disabled-chain output remains unchanged.
- `presets/Library.hpp` stores named user presets and favourites; factory data is read-only.
- `ui/Interface.hpp` uses original authored vector components, the existing family identity and real controls. No invented MIDI/auxiliary ports are exposed.
- `visualisations/EnergyField.hpp` uses safe atomic output measurements. It is an artistic energy visualisation, not a calibrated spectrum or a claim about unavailable DSP internals.
- WAV bank import and audio-input firmware capture were removed at the owner's request. PRO retains restoration of existing custom-bank patch data; curated editions retain their built-in banks.
- All three editions use unique plugin/module pairs. Free is part of the family plugin; Studio and PRO are separately packaged. Both paid editions share the family GPL licence.

## Edition status and remaining work

The owner requested the final split after Linux engine and GUI verification: Free 12, Studio 64, PRO 246. Curated editions compile only their selected program banks; PRO retains its full engine and composition functionality. Stable catalogue identities map shared presets between editions. The initial eight slots remain stable. Unsupported named presets are rejected with an explanation; older full-development patches should be opened in PRO to preserve sounds using unavailable effects.

Linux builds, real Rack loading, VM/host parity, disk-library operations and focused edition boundaries have passed. Multiplatform SDK packaging is being validated in CI. Earlier Grainloom platform results are not used as evidence of SONAVYRE compatibility. See VALIDATION.md for actual evidence.

The following are technical limitations or further production work, not a claim that every missing PRO enhancement prevents a useful Free release:

1. Inherited program-selection parameter-name strings and some UI/audio host state are not fully synchronized. Replace those paths with a safe state handoff before claiming comprehensive realtime safety.
2. Complete click-free program transitions, harden PRO legacy-bank JSON restoration, validate imported preset sizes/ranges/schema and improve concurrent library editing/error reporting.
3. Expand PRO graphical stage editing, effect-order changes, stage gain UI, undo/redo coverage, preset dirty-state indication and recent-effects tracking. Current detailed editing uses menus; the on-screen stage toggles control real audio processing.
4. Complete additional reset scopes and imported-bank identity handling. Module reset preserves user slots and the disk library; no reset should silently delete user presets.
5. Category-specific visual modes, calibrated/held meters and additional performance feedback remain beyond the current energy visualization.
6. Continue sustained audio, modulation/routing, patch restart and GUI workflow validation. Native Rack execution on Windows/macOS is distinct from successful SDK compilation.

The Library update draft is in LIBRARY-UPDATE.md. No store submission, published release or maintainer message has been sent. The feature branch may be pushed for CI without publishing a release.
