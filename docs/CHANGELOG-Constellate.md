# Changelog

## 2.1.2

- Rebuilt the knob decorations as true concentric circular sweeps so they remain visible beyond the knob shadows.
- Reduced the visual size of every input and output jack and tightened the colored output rings to match the concept artwork.
- Added the concept artwork's small gold registration dots beneath the port rows.

## 2.1.1

- Improved the legibility and alignment of the lower control and port labels.
- Added a 15-second performance demo to the repository and README.

## 2.1.0

- Refined the panel to match the original concept artwork at 15 HP.
- Added illuminated square LEARN and HOLD controls.
- Added engraved-gold typography, control arcs, panel depth, and route stars.
- Added bipolar MORPH CV attenuation for external LIVE/DREAM control.
- Made display routes frame-responsive and semantically mapped to A-D: probability controls line weight, evidence controls route stars, and emitted transitions drive directional beads.
- Added deterministic coverage for HOLD learning isolation and MORPH CV range/inversion.
- Preserved DSP behavior, parameter IDs, port IDs, and patch memory compatibility.

## 2.0.0

- Initial release of Constellate.
- Four-channel live trigger learning and routing.
- Variable-order event memory with one-to-four-event contexts.
- Affinity, drift, density, and live/dream performance controls.
- Clocked and learned-timing free-run generation.
- Persistent sparse transition model and timing memory.
- THREAD confidence CV and live constellation display.
