# SONAVYRE STUDIO

Separate paid-edition candidate: plugin `halfagiraf-sonavyre-studio`, module `SonavyreStudio`. Shares the compact interface, FV-1 processing, presets, modulation and visualisations with the family product. Contains 64 curated factory programs. Processing combinations and the full catalogue remain PRO features.

Build from here using `make RACK_DIR=/absolute/path/to/Rack-SDK dist`. GPL-3.0-or-later applies; commercial sale does not remove source redistribution obligations. This package has not been submitted to the VCV Store; pricing and commercial onboarding remain pending. See `../../docs/sonavyre/AUDIT.md` for release blockers and provenance.
