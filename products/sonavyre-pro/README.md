# SONAVYRE PRO development build

This is a separate Rack plugin (`halfagiraf-sonavyre-pro/SonavyrePro`), sharing the family's SONAVYRE source and new assets. Build from this folder with `make RACK_DIR=/absolute/path/to/Rack-SDK`. `prepare_resources.py` stages only the shared SONAVYRE assets and legal documents; the complete 200-program bank is compiled into the shared host following the project owner’s explicit confirmation of rights, alongside the eight preserved original programs.
