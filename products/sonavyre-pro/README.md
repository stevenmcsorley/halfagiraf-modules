# SONAVYRE PRO development build

This is a separate Rack plugin (`halfagiraf-sonavyre-pro/SonavyrePro`), sharing the family's SONAVYRE source and new assets. Build from this folder with `make RACK_DIR=/absolute/path/to/Rack-SDK`. `prepare_resources.py` stages only the shared SONAVYRE assets and legal documents; no third-party extracted firmware is copied.

This is GPL-3.0-or-later development code, not a cleared commercial release. See `../../docs/sonavyre/AUDIT.md` for rights, corresponding-source and engineering blockers.
